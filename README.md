# Homebrew Tap for SimpleFlowHarness

This is the official Homebrew Tap for
[SimpleFlowHarness](https://github.com/Aero123421/SimpleFlowHarness), the
`sfh` workflow runner for AI CLI agents and ordinary commands.

Install on macOS or Linux:

```bash
brew install Aero123421/tap/sfh
```

Upgrade:

```bash
brew upgrade sfh
```

The Formula installs the immutable, checksum-verified binary from the matching
GitHub Release. It supports Apple Silicon, Intel macOS, Linux arm64, and Linux
x86-64.

Formula updates are tested on macOS and Linux before the synchronization
workflow commits them. Report sfh problems in the
[main repository](https://github.com/Aero123421/SimpleFlowHarness/issues).
